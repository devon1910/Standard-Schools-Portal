# Standard Schools Portal User Guide

This guide follows the names and buttons shown in the portal.

## Sign in

1. Open the portal and enter your username and password.
2. Select **Sign in**.
3. If you were given a temporary password, create a new password when prompted.

Use the session selector at the top of the portal to choose the academic session you are working on.

## Overview

Open **Overview** to see the current session summary and shortcuts for common tasks. The setup checklist shows what still needs to be prepared.

## Recommended order of work

For a new session, use this order:

1. Set up the session, classes and subjects in **Academics**.
2. Add students in **Students**, or move existing students forward in **Promotion**.
3. Configure class subjects and enter scores in **Score sheets**.
4. Complete attendance, behaviours and remarks in **Report cards**.
5. Preview, publish and print the report cards.

## Academics

Owners can manage the academic structure.

### Create a session

1. Open **Academics**.
2. Open **Create session**.
3. Enter the **Session name**, such as `2026/2027`.
4. Select **Create**.

### Add a class

1. Open **Academics** and choose the academic session.
2. In **Add class**, enter the **Class name**.
3. Choose the **Class category** and optionally enter the **Class teacher**.
4. Select **Add class**.

### Add a subject

1. Open **Academics**.
2. Open **Add subject**.
3. Enter the **Subject name** and choose its **Class category**.
4. Select **Save subject**.

## Students

### Add a student

1. Open **Students**.
2. Open **Add student**.
3. Enter the student's details and choose the correct **Session** and **Class**.
4. Select **Save student**.

Each student has one permanent profile. Their class history is stored separately for each session.

### Add or replace a passport photograph

1. Open **Students** and find the student by name or admission number.
2. Select **View** beside the student.
3. Select **Upload passport photo**.
4. Choose a JPG, PNG or WebP image no larger than 5 MB.

The saved photograph appears automatically on that student's report cards. Uploading another photograph replaces the previous one.

### Update first-term fees

Owners can select **Fees** beside a student, enter the **Outstanding balance**, choose whether the fee is paid, and select **Update**.

### Archive a student

Owners can open a student's profile and select **Archive student**. Archiving keeps the student's history.

## Promotion

Use **Promotion** when starting a new academic session from an existing one.

1. Open **Promotion**.
2. Choose **Copy classes from** and enter the **New session name**.
3. Select **Create and review students**.
4. For each old class, choose the class students will be promoted into.
5. Review every student and choose **Promote**, **Left school** or **Graduated**.
6. Select **Confirm session promotion**.

No student is moved until the final confirmation.

## Question bank

### Upload a question

1. Open **Question bank**.
2. Open **Upload question**.
3. Choose the session, term, class, subject and assessment type.
4. Choose the file and select **Upload question**.

Files must be 10 MB or smaller. The portal accepts images, PDF files and Word documents.

Use the filters and select **Apply** to find a question. Select **Open file** to view it.

## Score sheets

### Configure subjects for a class

1. Open **Score sheets**.
2. Choose the session, term, class and subject, then select **Open sheet**.
3. Open **Configure subjects for _class name_**.
4. Owners can select the subjects taught in that class and select **Save subject list**.

### Enter scores

1. Open the required score sheet.
2. Enter **First test /20**, **Second test /20** and **Exam /60** for each student.
3. Select **Save score sheet**.

The total and grade are calculated automatically. The report-card grading scale is:

| Score | Grade |
| --- | --- |
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| 40–49 | E |
| 0–39 | F |

## Report cards

### Set up the term

Owners must do this once for each session and term.

1. Open **Report cards**.
2. Choose the **Session**, **Term** and **Class**, then select **Open class**.
3. Open **Term report settings**.
4. Enter **School opened (days)**, **Next resumption date** and **Report title**.
5. Select **Save term settings**.

The school name, motto, address, phone number, logo and principal's name come from **Settings**.

### Prepare a student's report

1. Open **Report cards** and open the required class.
2. Select **Prepare** beside a student.
3. Enter **Times present**.
4. Choose a rating from 1 to 5 for every behaviour.
5. Enter the class teacher and principal remarks.
6. Select **Save report details**.

Select **Preview** to check one report card. Draft reports show a **DRAFT** watermark.

### Publish and print

1. Confirm that every student's scores and report details are complete.
2. Owners can select **Publish class reports**.
3. Select **Print class batch** to open all report cards for the class.
4. In the preview window, select **Print or save PDF** and use the browser's print dialog.

Publishing requires complete scores, attendance, all eight behaviour ratings, and both remarks for every active student in the class.

## Settings

Owners can open **Settings** to:

- Update the school name, short name, motto, address, phone numbers, principal's name and logo URL under **School identity**.
- Create an owner or staff account under **Add administrator**.
- Review administrators and their account status.

Changes to the school identity are used on report cards.

## Owner and staff access

- **Owners** can manage school settings, accounts, academics, promotion, fees, archiving and report publishing. They can also perform staff tasks.
- **Staff** can add students, upload passport photographs and question files, enter scores, prepare report details, preview reports and print reports.

## If something is missing

- Check that the correct academic session is selected at the top of the portal.
- Confirm that the student is enrolled in the selected session and class.
- Configure the class subjects before entering scores.
- Complete every score and report field before publishing.
- Ask an owner if a setting or action is unavailable to staff.
